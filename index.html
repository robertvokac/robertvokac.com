Introduction

Welcome to my personal website! I'm Robert Vokáč, a C++ software developer.

Below are some of my current and planned projects:

  • Mind Net: Universal data server
  • Free Eggbert: Revival of the classic game Speedy Blupi (Windows) via decompilation and improvements.
  • Mobile Eggbert: Porting Speedy Blupi (Windows Phone) to C++ and CNA.
  • CNA Library: A XNA-like framework built on SDL 3.
  • Galaxy Eggbert: A 3D version of Speedy Blupi using BGFX.
  • Free API: Partial implementation of WinAPI.
  • Free Direct: DirectX 3 implementation built on SDL 3.
