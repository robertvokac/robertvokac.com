Introduction

I am a Java and C++ software developer. In my free time I work on:
  1. the revival of game Speedy Blupi for Windows (1998, 2002) - decompilation, improvements
  2. the revival of game Speedy Blupi for Windows Phone (2013) - migration from C# and XNA to C++ and SDL 3
  3. the CNA library - XNA like wrapper around the SDL 3 library
  4. I also plan to create the game Galaxy Eggbert - 3D version of Speedy Blupi (2002), C++ and Ogre 3D will be used
