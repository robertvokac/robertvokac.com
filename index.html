Introduction

Welcome to my personal website! I'm Robert Vokáč, a passionate software developer specializing in Java and C++.
I dedicate a large portion of my free time for game development and the C++ programming language.

Below are some of the projects I’m currently working on:

  • The revival of the iconic game Speedy Blupi (1998, 2002) for Windows - focusing on decompilation and game improvements.
  • Porting Speedy Blupi to Windows Phone (2013) - migrating from C# and XNA to C++ and SDL 3 for a more modern experience.
  • Developing the CNA library - a powerful XNA-like wrapper built around the SDL 3 framework.
  • Planning the creation of Galaxy Eggbert - a 3D version of Speedy Blupi, leveraging C++ and Ogre 3D for graphics and physics.
