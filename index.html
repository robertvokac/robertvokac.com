Introduction

Welcome to my personal website! I'm Robert Vokáč, a C++ software developer.


Below are some of my current and planned projects:

  • Free Eggbert: Revival of the classic game Speedy Blupi (1998, 2001) for Windows via decompilation and improvements
  • Mobile Eggbert: Porting Speedy Blupi for Windows Phone (2013) to C++ and CNA
  • CNA Library: A XNA-like framework built on SDL 3
  • Galaxy Eggbert: A 3D version of Speedy Blupi game using Ogre 3D library
  • Free API: Partial implementation of WinAPI
  • Free Direct: DirectX 3 implementation build on SDL 3
