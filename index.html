ForgeTracker

Java/Spring Boot issue tracking and project management system

GitHub: github.com/robertvokac/forge-tracker · Stack: Java 25, Spring Boot 4, PostgreSQL, Flyway, JPA/Hibernate, Spring Security, Gradle, Docker Compose, Thymeleaf, REST API

  • Issue tracker inspired by Jira, Bugzilla, MantisBT, and GitHub Issues.
  • Designed to demonstrate practical Java backend skills through a real, long-term application.
  • Server-side UI with Thymeleaf so the project stays maintainable without a heavy frontend framework.
  • PostgreSQL schema with Flyway migrations and JPA/Hibernate persistence.
  • Spring Security authentication and planned role/project-based authorization.
  • REST API for future integrations, automation, companion services, and external tools.
  • Planned tests with JUnit, Spring Boot Test, Mockito, and Testcontainers.
